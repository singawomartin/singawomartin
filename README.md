# Hi, I'm Singawo Martin 👋

### Computer Science & Networking Student at ULK

I'm a Computer Science and Networking student at Kigali Independent University (ULK), Rwanda. I enjoy learning how technology works, solving technical problems, and putting what I learn into practice.

I'm particularly interested in networking, cybersecurity, IoT, and software development. I like working on practical projects that help me improve my skills and gain real experience.

## What I'm Interested In

- 🌐 **Networking:** Learning about routing, switching, VLANs, and network troubleshooting.
- 🔐 **Cybersecurity:** Exploring network security, cyber defense, and how to protect systems.
- 🤖 **IoT:** Working with Arduino, sensors, and projects that connect hardware with software.
- 💻 **Programming:** Practicing with C, C++, Python, JavaScript, PHP, and Node.js.
- 🗄️ **Databases:** Working with MySQL and learning how to manage data.
- 🖥️ **IT Infrastructure:** Gaining experience with Windows Server, Linux, and system administration.

## Projects I've Been Working On

- **Garage Management System** – A project focused on managing garage operations using web technologies and a database.
- **Smart Weather & Environmental Monitoring System** – An IoT project that collects environmental data using sensors and displays the results.
- **Pharmacy Finder System** – An idea I'm exploring to make it easier for people to connect with pharmacies.

## What I'm Learning

I'm currently improving my programming, Git and GitHub, networking, cybersecurity, data analysis, and cloud computing skills. I believe the best way to learn is by building things, making mistakes, and finding ways to improve.

## A Little About My Goals

My goal is to keep growing in the technology field, gain practical experience, and work on solutions that make a difference. I'm always happy to learn from others, share ideas, and collaborate on interesting projects.
